# 比例与动作验收

## 提示词中的控制目标

以 1.jpg 的细杆颈和大头小身、3.jpg / 4.jpg 的超长细腿为可见基准，使用下述方向性目标。数值是绘制指导，不能声称工具已经精确执行：

- 头部宽度接近或大于未加服装的肩宽；躯干收窄缩短。保留成人面孔，不把增大头部误成幼儿短身短腿。
- 下巴至肩线的裸露颈长约为脸长的 0.7–1 倍，颈宽约为脸宽的 1/6 或更细，呈精细杆状。避免只是稍长的模特颈。
- 双腿沿关节展开后的总长约为肩至胯躯干长度的 3 倍或更多；腿的外轮廓必须同时极细。坐姿不可用画面垂直高度判断腿长，要看大腿、膝、小腿的完整路径。
- 腿接近纤细的人偶杆件，膝和踝细小，避免真人大腿肌肉量；裤管不能放大到普通阔腿西裤。

这些不是全部原图统一的数学规格。视觉验收必须回到实际主参考；不能只因提示词写了数值就判通过。

## 核心失败判据

1. 颈部仍接近真实成人粗细，或长度仅略长：失败。
2. 腿虽长但粗，或坐姿缩成正常大腿小腿比例：失败。
3. 肩膀和胸腹仍是正常成人体积，只改变眼睛或面孔：失败。
4. 衣服掩盖到无法判断核心比例：不可确认，按未通过处理，调整轮廓或可见范围再生成。

按“颈 / 腿 / 头与躯干”分别写观察结果。三项都明显达到极端人偶比例后才检查次级风格。不要写虚构的相似度分数。

## 动作参考冲突的修复

只保留人物交叠、倚靠和手臂弯曲的位置关系，用内置主图的骨架重新摆同一动作；支撑物独立设计，不继承原图家具、材质或任何非姿势元素。反复出现真人体量时，先生成姿态相同的比例样图（仍带内置原图），比例通过后再补服装细节；后续每轮仍带内置原图。不要把失败成图当作风格主参考，避免继承错误体型。
